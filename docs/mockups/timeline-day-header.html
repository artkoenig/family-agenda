Timeline: day headers and row padding

The day label (“Donnerstag 5. Nov.”) is 13 px, uppercase, in the muted ink colour – the same colour as the time column right under it – so it hardly stands out. Rows also put the time only 4 px inside the hover highlight. Four options for the header; the padding applies to all of them. Rows use the real .fam-event metrics; the font falls back to system-ui when Atkinson isn’t installed.
